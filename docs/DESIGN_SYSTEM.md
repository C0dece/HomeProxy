# Дизайн-система

Общая тема находится в packages/ui/theme.css. Фон #0E1116, поверхность #161C24 и граница #2B3542 формируют холодную тёмную палитру. Акцент для действий и фокуса синий. Цвет состояния сопровождается текстом.

Интерфейсы используют Segoe UI и системные шрифты. Адреса и версии выделяются моноширинным шрифтом. Отступы 4, 8, 16, 24 и 32 пикселя. Карточки, поля, статусы и кнопки используют общие токены. Предусмотрены видимый фокус и reduced motion.

На узком экране таблицы Admin переходят в карточки с подписями. Agent учитывает безопасные области экрана. Browser показывает только домены, запросы к которым были замечены в активной вкладке.
