# Безопасность

- API требует HTTPS за пределами loopback-режима разработки. Ключ подключения находится во фрагменте URL и передаётся клиентом в теле запроса. Ключ устройства ограничен API своего профиля.
- Токены хранятся как SHA-256, учётные данные прокси шифруются AES-GCM. Защитите ключи, SQLite и резервные копии ACL. Agent защищает локальное состояние Windows DPAPI. Browser получает правила без паролей прокси.
- Управляющий API Agent и Clash API слушают loopback и требуют токен. Локальные прикладные HTTP/SOCKS-порты доступны локальным процессам. Не перенаправляйте их за пределы устройства.
- Отзыв закрывает API и VLESS. Старые резервные пароли могут работать на отключённом устройстве до синхронизации или ротации у провайдера.
- Блокировка действует для трафика через прикладной прокси. Системные TUN, WFP, DNS/IPv6 kill switch и Android lockdown требуют отдельных реализаций. Chromium применяет встроенные исключения loopback при работе с PAC.
- Публичные релизы требуют подписей и доверенного канала для ключа. Для распространения sing-box действуют условия его лицензии. Windows-пакет получает sing-box отдельно.
