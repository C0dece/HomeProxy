Локальная проверка поднимает отдельный HTTPS-узел для REALITY, HTTP origin, аутентифицированный CONNECT, API, Agent и опционально Chromium. Сервисы слушают loopback. Данные временные. Профили, системные маршруты и брандмауэр не меняются. Бюджеты RAM и CPU пока не подтверждены профилированием под нагрузкой.

Android-сценарий использует отдельный AVD и сохраняет снимки экрана в dist/qa/android-vpn.png и dist/qa/android-apps.png. Режим --system-vpn сохраняет также dist/qa/android-lockdown.png.
