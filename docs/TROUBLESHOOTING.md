# Диагностика

| Симптом | Что проверить |
| --- | --- |
| Агент не запускается | homeproxy-agent.exe, sing-box.exe и доступность loopback-портов 17770, 17771, 17772, 17773, 17774 |
| Ссылка просрочена или использована | Новая одноразовая ссылка нужного типа |
| Прокси недоступен | Адрес, пароль, IP-ограничения провайдера и успешный ответ probeUrl на HEAD |
| Активен резерв | Доступность VLESS, TLS-узла REALITY и основного HTTP CONNECT |
| Конфликт правила | Синхронизация и повторная отправка с текущей версией |
| Расширение не управляет прокси | Политика браузера, другое расширение и локальный Agent |
| Ошибка восстановления SQLite | Исходный ключ шифрования, целостность копии и остановка службы |

В Agent раздел «Диагностика» показывает проверку маршрутов и правило для домена. /healthz проверяет SQLite и процесс ядра.
